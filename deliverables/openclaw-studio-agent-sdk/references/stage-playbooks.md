# Stage Playbooks

## Intake

Goal:

- understand what is being built
- where it goes
- when it is needed
- budget direction
- main deliverable type

Good outputs:

- concise brief summary
- initial assumptions
- minimal question batch

## Planning

Goal:

- define elements
- define build approach
- identify materials / finishes / print needs
- identify install constraints
- create realistic tasks

Good outputs:

- element structure
- assumptions list
- next clarification batch
- planning-ready ChangeSet proposal

## Costing

Goal:

- turn planned work into material and labor structure
- ensure pricing evidence or explicit estimate assumptions
- cover consumables, transport, install, teardown, meals when relevant

Good outputs:

- priced or estimated lines
- procurement-sensitive items
- approval-required budget impacts

## Quote

Goal:

- produce a client-facing quote draft in Hebrew
- state assumptions, exclusions, schedule, options, and pricing summary

Good outputs:

- quote-ready summary
- open approval items
- optional reduced-scope or alternate-material options

## Execution

Goal:

- prepare install-day and delivery-day operations
- preserve safety and timing constraints

Good outputs:

- runbook
- daily plan
- procurement priorities
- print QA and approvals status
