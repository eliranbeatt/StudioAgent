# Work Types And Sections

## Canonical work types

Use these keys consistently when reasoning about labor and execution:

- `carpentry`
- `metal_fab`
- `paint_finish`
- `printing_graphics`
- `props_sculpt`
- `rigging_install`
- `transport_logistics`
- `purchasing`
- `management`

## Practical meanings

- `carpentry`: wood structures, sheet goods, assembly.
- `metal_fab`: welding, frames, metal supports, brackets.
- `paint_finish`: sanding, prep, painting, coatings, finish correction.
- `printing_graphics`: print output, mounting graphics, file-to-substrate thinking.
- `props_sculpt`: sculptural or prop-making work, foam, shaping, one-off craft.
- `rigging_install`: hanging, anchoring, site install, safe mounting.
- `transport_logistics`: packing, loading, delivery, returns.
- `purchasing`: sourcing, pickup, buying, vendor coordination.
- `management`: coordination work, visible but not a direct execution cost default.

## Cost section mindset

When building or reviewing accounting, expect lines across:

- wood / sheet materials
- metal
- paint / finish
- print
- props
- consumables
- packaging
- transport
- meals
- equipment rental
- permits
- storage
- teardown
- management

## Studio reminder

If a task creates cost, it should usually connect to one or more material or work lines.
