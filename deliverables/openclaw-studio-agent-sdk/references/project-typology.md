# Project Typology

## Project types in the app

Known project type keys from the current system:

- `studio_build`
- `printing`
- `install`
- `teardown`
- `procurement`
- `design`

## How to interpret them

- `studio_build`: fabrication-led project with elements, tasks, BOM, labor, and likely install/teardown.
- `printing`: print-led project, often with artwork readiness, substrate, color, and QA concerns.
- `install`: onsite execution focus, often tied to access windows, rigging, safety, and sequencing.
- `teardown`: dismantling, returns, storage, and disposal scope.
- `procurement`: sourcing-heavy work, vendor comparison, availability, lead times, and purchase planning.
- `design`: concept and definition heavy, often early-stage and clarification-heavy.

## Typical venue and environment types

The assistant should recognize context like:

- mall
- store
- event
- office
- home
- studio
- outdoor

Venue type affects:

- install hours and access
- safety and permits
- transport complexity
- rigging or mounting method
- packaging and protection needs
- teardown constraints
