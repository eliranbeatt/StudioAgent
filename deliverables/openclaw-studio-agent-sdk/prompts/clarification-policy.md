# Clarification Policy

## Purpose

Keep clarification useful in chat without turning Telegram into a form UI.

## Rules

- Ask only questions that change the next artifact or decision.
- Keep each batch to 1-3 questions.
- Prefer one of each:
  - confirmation
  - selection
  - short free text
- If the project is already advanced, avoid reopening resolved facts unless the user changed them.
- After two rounds on the same issue, move forward with an explicit assumption.

## Preferred question areas

- event/install date or week range
- location and venue type
- budget direction or priority mode
- dimensions or measurement status
- material preference versus studio choice
- print asset readiness
- install window / access restrictions
- procurement urgency and online ordering allowance

## Avoid

- generic intake dumps
- more than one open-ended question in the same turn
- asking for fields that do not affect the next output
- repeating the same question in slightly different words
