### Hybrid LM Studio Config: Hosted Primary, Local Fallback

Source: https://github.com/openclaw/openclaw/blob/main/docs/gateway/local-models.md

```json5
        "anthropic/claude-sonnet-4-5": { "alias": "Sonnet" },

        "anthropic/claude-opus-4-6": { "alias": "Opus" },
      },
    },
  },
  "models": {
    "mode": "merge",
    "providers": {
      "lmstudio": {
        "baseUrl": "http://127.0.0.1:1234/v1",
        "apiKey": "lmstudio",
        "api": "openai-responses",
        "models": [
          {
            "id": "minimax-m2.5-gs32",
            "name": "MiniMax M2.5 GS32",
            "reasoning": false,
            "input": ["text"],
            "cost": { "input": 0, "output": 0, "cacheRead": 0, "cacheWrite": 0 },

    },
  },
```

### Model Tiering: Assign Models Based on Task Complexity (Prose)

Source: https://github.com/openclaw/openclaw/blob/main/extensions/open-prose/skills/prose/guidance/patterns.md

This pattern demonstrates assigning different AI models (Sonnet, Opus, Haiku) to tasks based on their complexity and required reasoning capabilities. It defines agents with specific models and orchestrates their execution within sessions, optimizing cost by using simpler models for simpler tasks.

```prose
agent captain:
  model: sonnet  # Orchestration and coordination
  persist: true  # Execution-scoped (dies with run)
  prompt: "You coordinate the team and review work"

agent researcher:
  model: opus  # Hard analytical work
```

### Check Cache TTL Eligibility for Kilo Gateway and Anthropic Models (TypeScript)

Source: https://github.com/openclaw/openclaw/blob/main/docs/design/kilo-gateway-integration.md

This function determines if a provider and model combination is eligible for cache Time-To-Live (TTL) optimization. It specifically checks for 'anthropic', 'openrouter' with Anthropic models, and 'kilocode' with Anthropic models. The function normalizes provider and model IDs to lowercase for case-insensitive comparison.

```typescript
export function isCacheTtlEligibleProvider(provider: string, modelId: string): boolean {
  const normalizedProvider = provider.toLowerCase();
  const normalizedModelId = modelId.toLowerCase();
  if (normalizedProvider === "anthropic") return true;
  if (normalizedProvider === "openrouter" && normalizedModelId.startsWith("anthropic/"))
    return true;
  if (normalizedProvider === "kilocode" && normalizedModelId.startsWith("anthropic/")) return true;
  return false;
}
```

Source: https://github.com/openclaw/openclaw/blob/main/docs/concepts/model-providers.md

Onboards the Z.AI provider using an API key. Aliases 'z.ai' and 'z-ai' are normalized to 'zai'.

```bash
openclaw onboard --auth-choice zai-api-key
```

### Disable Model TTS Overrides

Source: https://github.com/openclaw/openclaw/blob/main/docs/tts.md

This JSON configuration disables all model-driven TTS directives. When disabled, the model cannot emit `[[tts:...]]` tags to control voice or text formatting for TTS output.

```json
{
  "messages": {
    "tts": {
      "modelOverrides": {
        "enabled": false
      }
    }
  }
}
```

### Pin Channels to Specific Models in OpenClaw Config

Source: https://github.com/openclaw/openclaw/blob/main/docs/gateway/configuration-reference.md

Configure specific channel IDs to use particular models, overriding the default model selection. This is useful for tailoring responses based on the communication channel. Supports Discord, Slack, and Telegram.

```json5
{
  channels: {
    modelByChannel: {
      discord: {
        "123456789012345678": "anthropic/claude-opus-4-6"
      },
      slack: {
        "C1234567890": "openai/gpt-4.1"
      },
      telegram: {
        "-1001234567890": "openai/gpt-4.1-mini",
        "-1001234567890:topic:99": "anthropic/claude-sonnet-4-6"
      }
    }
  }
}
```

Source: https://github.com/openclaw/openclaw/blob/main/docs/providers/huggingface.md

### CLI Model Entry Configuration

Source: https://github.com/openclaw/openclaw/blob/main/docs/nodes/media-understanding.md

Defines a model entry of type 'cli' for media understanding. It specifies the command, arguments, size limits, timeout, and capabilities. CLI templates can use special variables like {{MediaPath}}.

```json
{
  "type": "cli",
  "command": "gemini",
  "args": [
    "-m",
    "gemini-3-flash",
    "--allowed-tools",
    "read_file",
    "Read the media at {{MediaPath}} and describe it in <= {{MaxChars}} characters."
  ],
  "maxChars": 500,
  "maxBytes": 52428800,
  "timeoutSeconds": 120,
  "capabilities": ["video", "image"]
}
```

### Custom Model Provider Configuration

Source: https://github.com/openclaw/openclaw/blob/main/docs/gateway/configuration-examples.md

Sets up custom model providers, merging configurations and defining a 'custom-proxy' provider with its base URL, API key, API type, and specific model details including ID, name, cost, and context window.

```json
{
  "models": {
    "mode": "merge",
    "providers": {
      "custom-proxy": {
        "baseUrl": "http://localhost:4000/v1",
        "apiKey": "LITELLM_KEY",
        "api": "openai-responses",
        "authHeader": true,
        "headers": {
          "X-Proxy-Region": "us-west"
        },
        "models": [
          {
            "id": "llama-3.1-8b",
            "name": "Llama 3.1 8B",
            "api": "openai-responses",
            "reasoning": false,
            "input": ["text"],
            "cost": {
              "input": 0,
              "output": 0,
              "cacheRead": 0,
              "cacheWrite": 0
            },
            "contextWindow": 128000,
            "maxTokens": 32000
          }
        ]
      }
    }
  }
}
```

### OpenClaw Fix: Google Gemini API Key Missing

Source: https://github.com/openclaw/openclaw/blob/main/docs/help/faq.md

This scenario occurs when OpenClaw attempts to use Google Gemini as a fallback model and cannot find the necessary API key. The solution involves either providing the Google authentication credentials or adjusting the model configuration to exclude Google models from the fallback list.

```bash
No API key found for provider "google"
```
