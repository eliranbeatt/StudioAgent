### Set Voice Wake Triggers

#### Description
Sets or updates the global list of voice wake word triggers. Changes are persisted by the Gateway and broadcast to all connected clients and nodes.

### Method
`POST` (Implicit via `voicewake.set` RPC)

### Endpoint
N/A (RPC call)

### Parameters
#### Request Body
- **triggers** (string[]) - Required - An array of strings representing the new global wake word triggers. Triggers are normalized (trimmed, empties dropped). Empty lists fall back to defaults. Limits are enforced for safety (count/length caps).

  "params": {
    "triggers": ["openclaw", "newwake", "ai assistant"]
  }
}

### Response
#### Success Response (200)
- **triggers** (string[]) - An array of strings representing the updated global wake word triggers.

#### Response Example

{
  "triggers": ["openclaw", "newwake", "ai assistant"]
}
```

Configure webhook security settings to manage trusted hosts, forwarding headers, and proxy IPs for secure webhook integrations.

```APIDOC
## Webhook Security

When a proxy or tunnel sits in front of the Gateway, the plugin reconstructs the
public URL for signature verification. These options control which forwarded
headers are trusted.

`webhookSecurity.allowedHosts` allowlists hosts from forwarding headers.

`webhookSecurity.trustForwardingHeaders` trusts forwarded headers without an allowlist.

`webhookSecurity.trustedProxyIPs` only trusts forwarded headers when the request
remote IP matches the list.

Webhook replay protection is enabled for Twilio and Plivo. Replayed valid webhook
requests are acknowledged but skipped for side effects.

Twilio conversation turns include a per-turn token in `<Gather>` callbacks, so
stale/replayed speech callbacks cannot satisfy a newer pending transcript turn.

### Example with a stable public host

```json
{
  "plugins": {
    "entries": {
      "voice-call": {
        "config": {
          "publicUrl": "https://voice.example.com/voice/webhook",
          "webhookSecurity": {
            "allowedHosts": ["voice.example.com"]
          }
        }
      }
    }
  }
}
```

### Add System.Echo Method: Server Handler (TypeScript)

Source: https://github.com/openclaw/openclaw/blob/main/docs/concepts/typebox.md

This code implements the server-side handler for the 'system.echo' method. It takes the 'text' parameter, processes it, and sends back a success response.

```typescript
import { GatewayRequestHandlers } from '../gateway';

export const systemHandlers: GatewayRequestHandlers = {
  "system.echo": ({ params, respond }) => {
    const text = String(params.text ?? "");
    respond(true, { ok: true, text });
  },
};
```
