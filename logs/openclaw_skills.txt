### Weather Skill API

Source: https://github.com/openclaw/openclaw/blob/main/skills/weather/SKILL.md

This section details how to use the Weather Skill to get current weather conditions and forecasts. It outlines when to use the skill, when not to use it, and provides examples for various query types.

```APIDOC
## Weather Skill API

### Description
Provides current weather conditions and forecasts for a specified location using the wttr.in service.

### Method
GET

### Endpoint
`https://wttr.in/[location]`

### Parameters
#### Path Parameters
- **location** (string) - Required - The city, region, or airport code for which to retrieve weather information.

#### Query Parameters
- **format** (string) - Optional - Specifies the output format. Common formats include `3` (one-line summary), `0` (detailed current conditions), `v2` (week forecast), `j1` (JSON output).
- **[format_code]** (string) - Optional - Used with `format=%c+%t+%w` etc. to customize output fields. See Format Codes below.

#### Request Body
This endpoint does not require a request body.

### Request Example
```bash
# One-line summary for London
curl "https://wttr.in/London?format=3"

# Detailed current conditions for New York
curl "https://wttr.in/New+York?0"

# 3-day forecast for London
curl "https://wttr.in/London"

# Week forecast for London
curl "https://wttr.in/London?format=v2"

# Specific day forecast (e.g., tomorrow)
curl "https://wttr.in/London?1"

# Custom formatted output
curl "https://wttr.in/London?format=%l:+%c+%t+%w"

# JSON output
curl "https://wttr.in/London?format=j1"

# PNG image output
curl "https://wttr.in/London.png"

The `--each` flag processes each item individually, and `--item-key message` specifies the key for the item. The `--args-json` provides structured arguments for the invoked tool.

```bash
gog.gmail.search --query 'newer_than:1d' \
  | openclaw.invoke --tool message --action send --each --item-key message --args-json '{"provider":"telegram","to":"..."}'
```
