### Configure Hybrid Model Routing with Local Heartbeat Override

Source: https://clawdocs.org/guides/cost-management

This configuration sets a default 'claude-sonnet-4' model for the brain but overrides it to use a local 'qwen3:14b' model for heartbeats. This strategy leverages cost-effective local models for routine tasks while using a more powerful model for general processing.

```yaml
brain:
  provider: "anthropic"
  model: "claude-sonnet-4"
  
  # Use local model for heartbeat  
  heartbeat_override:
    provider: "local"
    local:
      endpoint: "http://localhost:11434"
      model: "qwen3:14b"
      type: "ollama"

```
