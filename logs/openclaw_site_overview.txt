### Improve Clipboard Copy Handler with Fallback and Feedback

Source: https://github.com/openclaw/openclaw.ai/blob/main/OPTIMIZATIONS_SUMMARY.md

Enhances the clipboard copy functionality by adding a fallback mechanism using `execCommand` for older browsers and providing visual feedback for both success and failure. Includes null checks for icon elements and validation for command keys.

```javascript
let success = false;
try {
  if (navigator.clipboard && navigator.clipboard.writeText) {
    await navigator.clipboard.writeText(code);
    success = true;
  } else {
    // Fallback using textarea + execCommand
    const textArea = document.createElement('textarea');
    textArea.value = code;
    textArea.style.position = 'fixed';
    textArea.style.opacity = '0';
    document.body.appendChild(textArea);
    textArea.select();
    success = document.execCommand('copy');
    document.body.removeChild(textArea);
  }
} catch (err) {
  console.error('Failed to copy:', err);
  success = false;
}

if (success) {
  // Success feedback (green checkmark)
} else {
  // Visual error feedback - brief red flash
  btn.style.background = 'rgba(239, 68, 68, 0.3)';
  setTimeout(() => {
    btn.style.background = '';
  }, 1000);
}
```
