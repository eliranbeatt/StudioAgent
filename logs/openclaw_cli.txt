### Enable Node.js Module Compile Cache for Faster CLI Startup

Source: https://github.com/openclaw/openclaw/blob/main/docs/platforms/raspberry-pi.md

This script enhances CLI startup performance on Raspberry Pi by enabling Node.js's module compile cache. It adds an export for `NODE_COMPILE_CACHE` to `~/.bashrc`, creates the cache directory, and sets `OPENCLAW_NO_RESPAWN` to prevent extra startup costs. Subsequent CLI runs will benefit from the cached compiled modules.

```bash
grep -q 'NODE_COMPILE_CACHE=/var/tmp/openclaw-compile-cache' ~/.bashrc || cat >> ~/.bashrc <<'EOF'
export NODE_COMPILE_CACHE=/var/tmp/openclaw-compile-cache
mkdir -p /var/tmp/openclaw-compile-cache
export OPENCLAW_NO_RESPAWN=1
EOF
source ~/.bashrc
```

Source: https://github.com/openclaw/openclaw/blob/main/docs/cli/directory.md

This section details the `openclaw directory` command and its subcommands for managing contacts, groups, and self information within different channels. It also covers common flags and ID formats.

```APIDOC
## `openclaw directory`

Directory lookups for channels that support it (contacts/peers, groups, and “me”).

### Common flags

- `--channel <name>`: channel id/alias (required when multiple channels are configured; auto when only one is configured)
- `--account <id>`: account id (default: channel default)
- `--json`: output JSON

### Notes

- `directory` is meant to help you find IDs you can paste into other commands (especially `openclaw message send --target ...`).
- For many channels, results are config-backed (allowlists / configured groups) rather than a live provider directory.
- Default output is `id` (and sometimes `name`) separated by a tab; use `--json` for scripting.

### Using results with `message send`

```bash
openclaw directory peers list --channel slack --query "U0"
openclaw message send --channel slack --target user:U012ABCDEF --message "hello"
```

### ID formats (by channel)

- WhatsApp: `+15551234567` (DM), `1234567890-1234567890@g.us` (group)
- Telegram: `@username` or numeric chat id; groups are numeric ids
- Slack: `user:U…` and `channel:C…`
- Discord: `user:<id>` and `channel:<id>`
- Matrix (plugin): `user:@user:server`, `room:!roomId:server`, or `#alias:server`
- Microsoft Teams (plugin): `user:<id>` and `conversation:<id>`
- Zalo (plugin): user id (Bot API)
- Zalo Personal / `zalouser` (plugin): thread id (DM/group) from `zca` (`me`, `friend list`, `group list`)

## Self (“me”)

```bash
openclaw directory self --channel zalouser
```

## Peers (contacts/users)

```bash
openclaw directory peers list --channel zalouser
openclaw directory peers list --channel zalouser --query "name"
openclaw directory peers list --channel zalouser --limit 50
```

## Groups

```bash
openclaw directory groups list --channel zalouser
openclaw directory groups list --channel zalouser --query "work"

```

After installation, use these command-line interface (CLI) commands to verify that OpenClaw is functioning correctly. These commands check for configuration issues, display the gateway status, and launch the user interface.

```bash
openclaw doctor         # check for config issues
openclaw status         # gateway status
openclaw dashboard      # open the browser UI
```

### CLI Setup for Kilo Gateway API Key

Source: https://github.com/openclaw/openclaw/blob/main/docs/providers/kilocode.md

Configure the Kilo Gateway API key using the OpenClaw CLI or by setting an environment variable. This key is essential for authenticating requests to the Kilo Gateway.

```bash
openclaw onboard --kilocode-api-key <key>
```

```bash
export KILOCODE_API_KEY="your-api-key"
```

### Install OpenClaw CLI with Bash Script

Source: https://github.com/openclaw/openclaw/blob/main/docs/install/installer.md

Installs the OpenClaw CLI using a curl command to download and execute a bash script. Supports default installation, custom prefixes and versions, JSON output for automation, and running onboarding.

```bash
curl -fsSL --proto '=https' --tlsv1.2 https://openclaw.ai/install-cli.sh | bash
```

```bash
curl -fsSL --proto '=https' --tlsv1.2 https://openclaw.ai/install-cli.sh | bash -s -- --prefix /opt/openclaw --version latest
```

```bash
curl -fsSL --proto '=https' --tlsv1.2 https://openclaw.ai/install-cli.sh | bash -s -- --json --prefix /opt/openclaw
```

```bash
curl -fsSL --proto '=https' --tlsv1.2 https://openclaw.ai/install-cli.sh | bash -s -- --onboard
```

### Peekaboo CLI: Target by Window ID

Source: https://github.com/openclaw/openclaw/blob/main/skills/peekaboo/SKILL.md

Shows how to target UI elements and perform actions within a specific application window using its unique ID. This is useful when dealing with multiple instances of the same application or when window titles might not be unique. Commands include listing windows, clicking elements, and typing text.

```bash
peekaboo list windows --app "Visual Studio Code" --json
peekaboo click --window-id 12345 --coords 120,160
peekaboo type "Hello from Peekaboo" --window-id 12345
```

### Peekaboo CLI: Capture Screenshots and Analyze

Source: https://github.com/openclaw/openclaw/blob/main/skills/peekaboo/SKILL.md

Demonstrates capturing different types of screenshots using the `image` and `see` commands. It includes capturing the entire screen, analyzing screen content with a prompt, and capturing specific window content. The `--retina` flag is used for high-resolution captures.

```bash
peekaboo image --mode screen --screen-index 0 --retina --path /tmp/screen.png
peekaboo image --app Safari --window-title "Dashboard" --analyze "Summarize KPIs"
peekaboo see --mode screen --screen-index 0 --analyze "Summarize the dashboard"
```

### gog CLI Email Formatting Examples

Source: https://github.com/openclaw/openclaw/blob/main/skills/gog/SKILL.md

Illustrates different methods for formatting email bodies when sending messages via the gog CLI. Covers plain text via stdin, multi-line messages using heredocs, and HTML formatting for rich content.

```bash
# Example (plain text via stdin):
gog gmail send --to recipient@example.com \
  --subject "Meeting Follow-up" \
  --body-file - <<'EOF'
Hi Name,

Thanks for meeting today. Next steps:
- Item one
- Item two

Best regards,
Your Name
EOF

# Example (HTML list):
gog gmail send --to recipient@example.com \
  --subject "Meeting Follow-up" \
  --body-html "<p>Hi Name,</p><p>Thanks for meeting today. Here are the next steps:</p><ul><li>Item one</li><li>Item two</li></ul><p>Best regards,<br>Your Name</p>"
```

### Configure CLI Remote Defaults for Gateway Access

Source: https://github.com/openclaw/openclaw/blob/main/docs/gateway/remote.md

This JSON configuration snippet sets the default remote gateway URL and token for CLI commands. When the gateway is loopback-only, this configuration, combined with an active SSH tunnel, allows CLI tools to connect to the remote gateway.

```json5
{
  "gateway": {
    "mode": "remote",
    "remote": {
      "url": "ws://127.0.0.1:18789",
      "token": "your-token"
    }
  }
}
```

### Control Hue Lights with OpenHue CLI

Source: https://github.com/openclaw/openclaw/blob/main/skills/openhue/SKILL.md

Commands to control individual Hue lights, including turning them on/off, adjusting brightness, setting color temperature, and changing color. Supports color names and hex codes.

```bash
# Turn on/off
openhue set light "Bedroom Lamp" --on
openhue set light "Bedroom Lamp" --off

# Brightness (0-100)
openhue set light "Bedroom Lamp" --on --brightness 50

# Color temperature (warm to cool: 153-500 mirek)
openhue set light "Bedroom Lamp" --on --temperature 300

# Color (by name or hex)
openhue set light "Bedroom Lamp" --on --color red
openhue set light "Bedroom Lamp" --on --rgb "#FF5500"
```
